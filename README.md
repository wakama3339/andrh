# AndrH - Cloud Data & File Storage

Проект для загрузки и сохранения файлов в облаке с использованием Next.js (App Router) и Vercel Blob.

## Возможности
- 📤 Загрузка любых файлов (drag-and-drop / выберите файл)
- 💾 Реальное сохранение файлов в Vercel Blob Store
- 🔗 Прямые ссылки на скачивание и просмотр файлов
- 🗑️ Возможность удаления файлов
- 📝 Локальный блокнот с автосохранением в браузере

## Инструкция по деплою на Vercel

1. Установите Vercel CLI (если не установлен):
   ```bash
   npm i -g vercel
   ```

2. Выполните команду деплоя в корне проекта:
   ```bash
   vercel
   ```

3. **ВАЖНО: Включите Vercel Blob Store**:
   - Перейдите в ваш проект в панели [Vercel Dashboard](https://vercel.com/dashboard).
   - Зайдите во вкладку **Storage** -> Нажмите **Create Database / Store** -> Выберите **Blob**.
   - Назовите хранилище (например, `andrh-blob`) и нажмите **Connect** к проекту `andrh`.
   - Vercel автоматически добавит переменные окружения `BLOB_READ_WRITE_TOKEN`.

4. Сделайте передеплой с подключенным хранилищем:
   ```bash
   vercel --prod
   ```
